## Automatic gates

`work/local-llm/qwen38-upgrade.mjs` waits up to 90 minutes for discovery, checks the two
download hashes, then runs the existing isolated 64K CLI validation with the new profile.
The validation covers Read, Edit, Bash, actual fixture tests, automatic compaction,
memory retention and session resume. Existing 95% VRAM/77% RAM guards remain active.
Any failed check stops without switching the employee. No current employee is interrupted.

On success it rechecks production idleness and unchanged original settings, registers the
new profile, then uses the existing session-locked profile-selection API. This creates a
new active session while preserving the old session history and the 3.6 profile/model.
The job does not claim testing has passed until the status file says completed.

Live progress: `work/reports/qwen38-upgrade-status.json`.
Validation output: `work/reports/qwen38-validation.log` (created after validation ends).
