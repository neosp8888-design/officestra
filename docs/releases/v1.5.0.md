# OFFICESTRA v1.5.0 — Community Preview

Five independent AI sessions now collaborate more clearly, with an experimental
path for running one of them on a validated local model host.

## English

- **Coworker-to-coworker turns:** GUI and terminal coworkers can delegate work
  through the local API. Messages show the sending coworker's name and avatar,
  while each CLI session remains independent.
- **Experimental Local AI:** opt-in local profiles can run through Claude Code
  or Codex compatibility paths. The newly validated direct path uses Codex,
  Responses tools, a pinned llama.cpp runtime, and Qwen3.8-27B with a 64K
  context. Local host address and reasoning controls are available in the app.
- **Tool-capable local Codex:** namespace tools, client-side tool search, custom
  tools, shell calls, computer use, and image results now round-trip through the
  local Responses bridge. Interrupted requests release owned GPU resources and
  are not retried silently.
- **Clearer usage and evaluation:** usage boards include a pace baseline, cost
  summaries include per-minute averages, and coworker evaluation reports offer
  a more useful breakdown.
- **More reliable terminal records:** terminal completion waits for delayed
  transcripts and preserves recovered activities and usage more consistently.
- **Updated Korean and English guides:** both READMEs now include copy-ready
  coworker collaboration instructions and explain cloud-only versus experimental
  local-model configuration.

### Download and install

Download `OFFICESTRA-1.5.0-macOS-arm64.dmg`, open it, and drag OFFICESTRA into
Applications. Preserve existing conversations and work data.

Apple silicon · macOS 14 or later · English/Korean. Node.js and the local backend
are bundled. Docker Desktop and the AI CLIs you use still require separate
installation and sign-in. Local AI additionally requires an operator-provisioned,
validated host profile; it is not required for normal cloud use.

This is an **ad-hoc signed, not Apple-notarized Community Preview**. If macOS
blocks launch, verify the source and use the app-specific **Open Anyway** option
in System Settings → Privacy & Security. Do not disable system-wide protections.

Use `SHA256SUMS` to verify the DMG. Displayed costs are not subscription charges.

## 한국어

- **직원 간 턴 전달:** GUI와 터미널 직원이 로컬 API로 일을 위임할 수 있습니다.
  메시지에 발신 직원의 이름과 얼굴을 표시하며, 각 CLI 세션은 독립적으로 유지합니다.
- **실험적 로컬 AI:** 선택형 로컬 프로필을 Claude Code 또는 Codex 호환 경로로
  실행할 수 있습니다. 새로 검증한 직접 실행 경로는 Codex·Responses 도구·고정된
  llama.cpp 런타임·64K 문맥의 Qwen3.8-27B를 사용합니다. 앱에서 로컬 PC 주소와
  추론 수준을 설정할 수 있습니다.
- **도구를 쓰는 로컬 Codex:** namespace 도구, 클라이언트 도구 검색, custom 도구,
  shell, 컴퓨터 사용과 이미지 결과가 로컬 Responses 브리지를 왕복합니다. 취소된
  요청은 소유한 GPU 자원을 반납하며 몰래 재시도하지 않습니다.
- **사용량·평가 개선:** 사용량 보드에 소진 속도 기준선을 추가하고, 비용 요약에 분당
  평균을 표시하며, 직원 평가 보고서를 더 유용하게 정리했습니다.
- **터미널 기록 안정화:** 늦게 기록되는 transcript를 기다려 완료 처리하고, 작업
  활동과 사용량을 더 안정적으로 보존합니다.
- **한·영 안내 갱신:** 두 README에 바로 사용할 수 있는 직원 협업 지침과 클라우드만
  쓸 때·실험적 로컬 모델을 쓸 때의 설정 차이를 추가했습니다.
