# OFFICESTRA v1.6.0 — Community Preview

## 한국어

분할 대화와 자동 전달을 중심으로 직원 협업을 개선하고, 긴 대화의 스크롤·창 크기 조절 및 로컬 모델 운영을 다듬었습니다.

- **분할 대화:** 두 직원의 대화를 나란히 열고, 클릭한 창을 공용 입력 대상으로 선택합니다. 직원별 작성 중인 글·첨부를 보존하며 로딩 중 연속 전환을 제한합니다.
- **여러 직원에게 자동 전달:** `@`로 수신자를 선택하고 직원별 설정을 유지합니다. 상대가 바쁘면 전달을 대기하고, 예약만 취소하거나 자동 전달을 일시정지할 수 있습니다.
- **스크롤과 창 조절:** 빠른 휠 입력과 스크롤 경계의 중복 처리를 줄이고, 창 드래그 중 중간 크기 변경을 합칩니다. 기존 시각 효과를 유지하며 창 크기와 위치를 복원합니다.
- **맨 아래 이동:** 직접 스크롤해 하단에서 한 화면 이상 떨어졌을 때 표시하고, 맨 아래에 도달하면 숨깁니다.
- **로컬 AI 운영:** 준비된 Claude Code·Codex 프로필의 모델 실행·중지, 공유 모델 자원 관리, 취소 후 정리를 개선했습니다. MeroMero 31B 텍스트 전용과 26B-A4B 이미지 입력 경로를 구분하고 모델별 추론 옵션을 제공합니다.
- **모델·사용량 표시:** CLI 설치·업데이트 후 모델 목록을 다시 확인하고, Claude 요금제 표시를 계정 프로필 기준으로 수정했습니다. 외부 개발 도구가 보고한 활동을 대화에 표시합니다.
- **개발용 테스트 출력:** 공통 실행 도구가 반복적인 시작·통과 메시지를 줄이면서 실패 상세·건너뜀·원문 로그·종료 코드를 보존합니다. 테스트 실행 속도나 API 요금의 일정 비율 개선을 의미하지 않습니다.

Apple silicon · macOS 14 이상 · 영문/한글. Node.js와 로컬 백엔드는 포함됩니다. Docker Desktop과 사용할 AI CLI의 설치·로그인은 별도로 필요합니다.

이 배포본은 **ad-hoc 서명·Apple 미공증 Community Preview**입니다. macOS가 실행을 차단하면 출처를 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 **그래도 열기**를 사용하세요.

로컬 AI는 운영자가 모델·런타임·SSH 호스트 프로필을 준비해야 하는 선택형 실험 기능입니다. 큰 이미지와 64K 문맥을 함께 사용하는 모든 GPU 구성을 보장하지 않습니다. Graft 등 외부 개발 도구와 개인용 훅은 배포 앱에 기본 포함되지 않습니다.

## English

This release improves coworker collaboration with split conversations and automatic forwarding, and refines scrolling, window resizing, and local-model operation.

- **Split conversations:** view two coworkers side by side and click a pane to target the shared composer. Keep drafts and attachments per coworker and gate repeated switches while loading.
- **Forward replies to multiple coworkers:** choose recipients with `@`, retain settings per coworker, wait for busy recipients, and pause or cancel pending deliveries.
- **Scrolling and resizing:** coalesce rapid wheel input and intermediate window sizes, reduce redundant work at scroll boundaries, preserve visual effects, and restore window size and position.
- **Jump to bottom:** show the button after manually scrolling at least one viewport away from the bottom; hide it on reaching the bottom.
- **Local AI operation:** improve start/stop controls, shared-model resources, and cancellation cleanup for provisioned Claude Code and Codex profiles. Separate text-only MeroMero 31B from the 26B-A4B image-input path and expose model-specific reasoning options.
- **Models and usage:** refresh model discovery after CLI installation or updates, read Claude plan labels from the account profile, and display activity reported by external developer tools.
- **Developer test output:** a shared runner reduces repetitive start/pass messages while retaining failure details, skips, raw logs, and exit codes. This is not a claim of a fixed reduction in execution time or API cost.

### Download and update

Open `OFFICESTRA-1.6.0-macOS-arm64.dmg` and drag OFFICESTRA into Applications. Preserve existing conversations, work records, and settings. Verify the download with `SHA256SUMS`.

Apple silicon · macOS 14 or later · English/Korean. Node.js and the local backend are bundled. Docker Desktop and your AI CLIs still require separate installation and sign-in.

This is an **ad-hoc signed, not Apple-notarized Community Preview**. If macOS blocks launch, verify the source and use the app-specific **Open Anyway** option in System Settings → Privacy & Security.

Local AI remains an opt-in experiment requiring operator-provisioned models, runtime, and SSH host profiles. Large images combined with 64K context are not guaranteed on every GPU configuration. External developer tools such as Graft and personal hooks are not bundled with the app.
