# OFFICESTRA v1.4.0 — Community Preview

Three AI providers, five independent sessions, one local control room.

## English

This release brings together 93 changes since v1.3.3.

- **GUI + real terminals:** switch into a coworker's interactive Claude Code,
  Codex, or Antigravity session. Terminal conversations, activities, and usage
  flow back into the same GUI history.
- **Automatic model discovery:** available models and supported reasoning
  options refresh automatically. Hide unwanted models and choose each
  coworker's model yourself.
- **Clearer usage tracking:** refreshed pricing catalogs, provider-specific
  limits, context compaction status, and cost highlights. Claude's reported
  costs are preserved; other costs are estimates based on token usage.
- **Shared knowledge:** local semantic RAG, structured response sources, and an
  improved internal wiki and conversation archive.
- **English and Korean:** expanded interface translations, with user-chosen
  coworker names preserved.
- **Smoother conversations:** scrolling and table-hover fixes, selectable text,
  code cards, rounded inline code, and more reliable terminal completion state.

### Download and install

- Download `OFFICESTRA-1.4.0-macOS-arm64.dmg` from this release.
- Requires an **Apple silicon Mac with macOS 14 or later**. Intel is not supported.
- Open the DMG and drag OFFICESTRA into Applications. Preserve existing data.
- Node.js and the local backend are bundled. Docker Desktop and the AI CLIs you
  use must be installed separately, with their own account sign-ins.
- This build is **ad-hoc signed, not Apple-notarized**. If macOS blocks launch,
  verify the source and use the app-specific **Open Anyway** option in System
  Settings → Privacy & Security. Do not disable system-wide security protections.
- `SHA256SUMS` is included to verify the downloaded DMG.

## 한국어

v1.3.3 이후 93개 변경 사항을 모았습니다.

- **GUI와 실제 터미널:** 직원의 Claude Code·Codex·Antigravity 세션을 터미널로
  열고, 대화·작업 내역·사용량을 같은 GUI 기록으로 이어갑니다.
- **모델 자동 수집:** 지원 모델과 추론 옵션을 자동 갱신합니다. 불필요한 모델만
  숨기고, 직원마다 사용할 모델을 직접 선택할 수 있습니다.
- **사용량을 더 명확하게:** 가격 카탈로그 갱신, 프로바이더별 한도, 컨텍스트 압축
  상태와 비용 강조 표시를 보강했습니다. Claude는 보고된 비용을 그대로 사용하며,
  나머지는 토큰 사용량에 따른 추정치입니다.
- **공유 지식:** 로컬 의미 검색 RAG, 구조화된 응답 근거, 사내 위키와 대화 보관함을
  개선했습니다.
- **영문·한글 UI:** 화면 번역을 확대하고 사용자가 정한 직원 이름은 유지합니다.
- **대화 화면 안정화:** 스크롤·표 호버 성능, 텍스트 선택·복사, 코드 카드와 둥근
  인라인 코드, 터미널 완료 상태 표시를 개선했습니다.
