# OFFICESTRA v1.7.0 — Community Preview

## 한국어

직원이 함께 쓰는 업무 보드와 티켓 검토 체계를 추가하고, 직원 응답을 소리로 읽어 주는 음성 지원(실험)을 넣었습니다. 정보 패널도 사용량 중심으로 정리했습니다.

- **업무 보드:** 프로젝트와 티켓을 로컬 DB에 저장하고 대시보드·WBS·칸반으로 봅니다. 담당자·완료자·검증자, 선행 작업, 주간·월간 목표, 업무 기록 연결, 진행·변경 이력을 남깁니다. 모든 CLI·모델이 같은 로컬 API로 읽고 씁니다.
- **티켓 유형과 검토:** 기획·구현·사전테스트·독립검증·조사·콘텐츠 제작·운영 유형별로 완료 근거를 받습니다. 사용자 검토 결과는 직원 검증과 따로 기록하며 로그인 신원 인증을 뜻하지 않습니다. 구현 티켓 완료에는 원격에 푸시한 커밋 SHA가 필요하고, 기존 티켓은 재분류하지 않습니다.
- **완료 프로젝트 정리:** 열린 티켓이 없는 프로젝트에 완료 배지를 달고 기본적으로 목록에서 숨깁니다. 스위치로 다시 볼 수 있습니다. 칸반의 여섯 상태 열이 창 폭 안에 들어오도록 고쳤습니다.
- **음성 지원(실험):** 실시간 대화 제목 줄의 버튼으로 선택한 직원의 응답을 완성된 문장부터 맥에서 Qwen3-TTS로 읽습니다. 한 번에 한 직원만 읽습니다. 합성용 Python 환경(`~/.officestra/voice/.venv`, mlx-audio)은 따로 설치해야 하며 개인 기준 음성 파일은 앱에 포함하지 않습니다. 문장 사이에 끊김이 생길 수 있습니다.
- **정보 패널:** 선택 버튼을 사무실 그림 아래로 옮겼습니다. 화이트보드 탭을 **사용량**으로 바꿔 기본으로 열고, 한도 새로고침은 작은 아이콘과 조회 시각으로 표시합니다. Claude·Antigravity 한도는 호출 제한 때문에 5분 간격으로 갱신됩니다.
- **안정성:** 직원 간 응답 전달과 Claude 사용량 기록을 안정화했습니다.

### 다운로드와 업데이트

`OFFICESTRA-1.7.0-macOS-arm64.dmg`를 열고 OFFICESTRA를 응용 프로그램 폴더로 옮기세요. 기존 대화·작업 기록과 설정을 지우지 마세요. `SHA256SUMS`로 다운로드 파일을 확인할 수 있습니다.

Apple silicon · macOS 14 이상 · 영문/한글. Node.js와 로컬 백엔드는 포함됩니다. Docker Desktop과 사용할 AI CLI의 설치·로그인은 별도로 필요합니다.

이 배포본은 **ad-hoc 서명·Apple 미공증 Community Preview**입니다. macOS가 실행을 차단하면 출처를 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 **그래도 열기**를 사용하세요.

로컬 AI와 음성 지원은 운영자가 모델·런타임을 준비해야 하는 선택형 실험 기능입니다. Graft 등 외부 개발 도구와 개인용 훅은 배포 앱에 기본 포함되지 않습니다.

## English

This release adds a shared work board with a ticket review model, an experimental voice readout of coworker replies, and a usage-first information panel.

- **Work board:** store projects and tickets in the local database and view them as a dashboard, WBS, or kanban. Track assignee, completer, and verifier, predecessors, weekly and monthly goals, linked work records, and progress and change history. Every CLI and model reads and writes through the same local API.
- **Ticket types and review:** planning, implementation, pretest, verification, research, content, and operations tickets each require matching completion evidence. User review is recorded separately from coworker verification and is not an authenticated sign-off. Implementation tickets need a pushed commit SHA to close; existing tickets are not reclassified.
- **Completed projects:** projects with no open work get a completed badge and are hidden from the list by default, with a switch to show them. The six kanban state columns now fit the window width.
- **Voice readout (experimental):** a button in the live conversation header reads the selected coworker's reply sentence by sentence with Qwen3-TTS on the Mac, one coworker at a time. The synthesis Python environment (`~/.officestra/voice/.venv`, mlx-audio) is installed separately, and personal reference voices are not bundled. Pauses between sentences may occur.
- **Information panel:** the selector sits below the office scene. The whiteboard tab is now **Usage** and opens by default; limit refresh is a compact icon with the fetch time. Claude and Antigravity limits refresh at most every five minutes because of rate limits.
- **Stability:** coworker reply delivery and Claude usage recording are more reliable.

### Download and update

Open `OFFICESTRA-1.7.0-macOS-arm64.dmg` and drag OFFICESTRA into Applications. Preserve existing conversations, work records, and settings. Verify the download with `SHA256SUMS`.

Apple silicon · macOS 14 or later · English/Korean. Node.js and the local backend are bundled. Docker Desktop and your AI CLIs still require separate installation and sign-in.

This is an **ad-hoc signed, not Apple-notarized Community Preview**. If macOS blocks launch, verify the source and use the app-specific **Open Anyway** option in System Settings → Privacy & Security.

Local AI and voice readout remain opt-in experiments requiring operator-provisioned models and runtimes. External developer tools such as Graft and personal hooks are not bundled with the app.
